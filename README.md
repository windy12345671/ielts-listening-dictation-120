# 听见 · 雅思听力填空练习

一个可在手机和电脑上使用的雅思听力词汇填空网页。用途是把高频词放进 Part 1 和 Part 4 风格的句子中，听句子、填单词，再通过错题和收藏复习拼写。练习句由词汇编写，不是雅思真题原声或官方题库。

**在线使用：** [打开练习网页](https://windy12345671.github.io/ielts-listening-dictation-120/)

## 功能

- 共 970 道填空题：原有 120 道练习，加上 850 道 Part 4 词汇练习。
- Part 4 按 17 套组织；每套 5 组，每组 10 题，保留主题标题。
- 提交后显示对错、正确拼写和句子翻译；错题可二刷，答对后移入回顾练习。
- 每题可收藏，收藏的单词可在独立板块背诵；练完可进行随机 20 题测试。
- 采用英式合成语音。联网时先使用网页中的“离线准备”下载音频，之后可在同一浏览器中离线练习。
- 学习进度、错题和收藏保存在当前浏览器中；换设备或清除网站数据后不会自动同步。

## 本地运行

这是静态网页。下载仓库后，在仓库目录运行本地静态服务器，例如：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/`。直接双击 `index.html` 也许能显示页面，但离线缓存需要 HTTP 或 HTTPS 环境。
